# Portfolio Assets Placeholder

Use this folder to keep portfolio-facing assets for the QCML project.

These files live inside the website workspace so the presentation layer and the recruiter-facing evidence stay with the product.

Recommended structure:
- `screenshots/`: homepage, atlas, lesson page, and dark-mode captures
- `demo-gifs/`: short looping product demos for GitHub or portfolio pages

These assets are not required for development, but they make the repository much stronger as a personal showcase project.
