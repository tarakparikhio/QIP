# PDF Sources

This folder contains the original source PDFs for the QCML lesson series.

These files are part of the website workspace on purpose: they preserve provenance for the curriculum and make the project easier to review as a portfolio piece.

## Files
- `quantum_midway_lessons_1_5.pdf` through `quantum_midway_lessons_31_35.pdf`: lesson source batches.
- `quantum_analogy_master_detailed.pdf`: supporting analogy reference used during preservation and enrichment.

These files should be treated as canonical source material.
