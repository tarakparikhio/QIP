# Source Context

This folder contains provenance and reference material for the curriculum.

## What Lives Here
- `lesson_index.md`: lesson-to-PDF page mapping
- `source_inventory.json`: structured extraction inventory
- `enrichment_rules.md`: content-preservation and enrichment policy
- `references/analogy_master.json`: analogy/reference material used during enrichment

## Why It Is Here
These files describe the source and the transformation rules, but they are not part of the active website runtime and they are not the main lesson-processing workspace.

That makes them metadata, not artifacts.

## Relation To Artifacts
- `artifacts/` = active pipeline outputs
- `/_metadata/source-context/` = provenance and descriptive source metadata
