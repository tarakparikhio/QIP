# Artifacts

This folder contains generated project outputs and working documents.

## Contents
- `raw_lessons/`: direct extracted text from the lesson PDFs, grouped by lesson batch.
- `references/`: extracted support material, such as the analogy handbook.
- `audits/`: gap reviews that identify where lessons are too vague or incomplete.
- `content/`: the main lesson workspace for unified JSON and readable Markdown.
- `web_preview/`: simple browser preview files for quick visual review.

## Top-Level Files
- `lesson_index.md`: map of lesson IDs to source PDFs and pages.
- `source_inventory.json`: structured source mapping for all PDFs.
- `enrichment_rules.md`: content-preservation and enrichment policy.
