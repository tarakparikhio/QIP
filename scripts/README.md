# Scripts

This folder contains the helper scripts used to build and review QCML content artifacts.

## Files
- `extract_qcml_pdfs.py`: extracts machine-readable lesson text from the PDFs.
- `audit_batch_1_5.py`: creates the first gap audit for lessons `1-5`.
- `build_review_views.py`: converts enriched JSON into readable Markdown and a simple HTML preview.
- `build_remaining_scaffolds.py`: creates source-preserving scaffolds for lessons `6-35`.
