# QCML Release Checklist

## Repo Readiness
- Root README explains the product clearly
- Website README explains architecture and deployment clearly
- Roadmap is up to date
- Prompt and plan files are in the correct `prompt/` locations

## Website Readiness
- `npm run typecheck` passes
- `npm run build` passes
- Homepage feels coherent in light and dark mode
- Atlas search/filter works correctly
- Lesson pages render math and navigation correctly

## Portfolio Assets
- At least 3 screenshots are prepared
- At least 1 short demo GIF or video is prepared
- Project summary text is ready for GitHub and portfolio use

## Deployment
- Decide deployment target:
  Vercel or Firebase Hosting
- Confirm production build output is current
- Confirm links and navigation work in deployed mode

## Post-Release
- Add live demo link to repo
- Add screenshots/GIFs to README if available
- Capture follow-up issues for the next roadmap phase
