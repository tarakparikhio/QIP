# QCML Roadmap

## v1
- Extract lesson content from source PDFs
- Preserve original analogies while enriching depth
- Convert lessons into structured JSON
- Generate readable Markdown review views
- Build the first Next.js website with lesson browsing and lesson detail pages

## v1.1
- Improve homepage information architecture
- Strengthen curriculum atlas UX and lesson discovery
- Refine navigation across homepage, atlas, and lesson detail pages
- Make the repo and product easier to present as a portfolio project
- Keep deployment simple on Vercel or Firebase Hosting

## v2
- Add `Intuition Mode` and `Rigor Mode`
- Add local-first progress tracking
- Add quick-look lesson previews from the atlas
- Add lightweight interactive widgets for “aha” moments
- Explore richer atlas, motion, and higher-end interactive presentation after the UX core is stable
